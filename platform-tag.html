2D Platform Tag Game

Project Overview

This project is a two-player platformer tag game developed in Processing (Java). Players move across multiple platforms while attempting to tag each other before the round timer expires. The game includes gravity, jumping mechanics, platform collision detection, score tracking, and a menu system.

Project Features

  • Two-player local multiplayer gameplay
  • Platform collision and gravity physics
  • Jumping and movement controls
  • 30-second round timer
  • Tag detection system
  • Score tracking between rounds
  • Main menu and game over screens
  • Custom background and character sprites

Controls

  • Player 1 (Red): W, A, D
  • Player 2 (Pink): Arrow Keys

Project Explanation

The objective of the game is to avoid being "It" when the timer reaches zero. At the beginning of each round one player is randomly selected as the chaser. Players can move across a multi-level platform map while attempting to escape or tag the opposing player.

The game uses arrays to store platform locations, custom functions to organize different game systems, and collision detection to determine when players land on platforms. A timer system controls the length of each round and automatically determines the winner when time expires.
